# Reporting a Vulnerability

Felicity is an offline music player, so most security concerns will likely involve local file handling, metadata parsing, or audio playback. If you discover a security vulnerability, please report it privately using GitHub's **Security** tab instead of opening a public issue.

You can also email me directly at [Hamza Rizwan](mailto:hamzarizwan243@gmail.com) (`hamzarizwan243@gmail.com`) with the subject `Felicity Security Vulnerability`. Please include enough details or steps to reproduce the issue so I can investigate and patch it.

Thank you for helping improve the security of Felicity.
